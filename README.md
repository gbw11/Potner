# Potner (S15P11E104)

> Pot + Partner. 스스로 판단하고 움직이며 사용자와 교감하는 반려식물 AIoT 로봇.
> SSAFY 15기 공통 프로젝트 · E104 팀

## 프로젝트 개요

Potner는 **화분을 싣고 다니는 반려식물 로봇** 프로젝트입니다. 판단은 서버가, 이동/수행은 로봇이,
집안 거치대(장치 스테이션)는 센서 수집과 급수·송풍·촬영을 맡는 구조로 역할이 나뉘어 있습니다.

- **자율 급수·송풍** — 장치 스테이션(라즈베리파이)이 온습도·조도·토양수분을 측정해 서버로 올리면,
  서버가 급수/송풍 필요 여부를 판단해 로봇 또는 스테이션에 명령을 내립니다.
- **자율 주행·도킹** — 로봇(Jetson)이 SLAM 지도 위에서 스테이션까지 비전 서보잉으로 도킹합니다.
- **대화·일기** — LLM이 센서 실측값과 대화 맥락을 근거로 식물의 상태를 브리핑하고, 1인칭 "식물 일기"를
  생성합니다. 판정(정상/이상)은 항상 로컬 규칙이 하고, LLM은 표현만 담당합니다.
- **앱 연동** — Flutter 앱에서 식물 상태 확인, 귀가 알림, 원격 급수/송풍 명령을 지원합니다.

이 저장소는 각 파트가 GitLab(`s15-webmobile3-sub1/S15P11E104`)에서 **파트별로 다른 브랜치**
(`App-*`, `Server-*`, `Robot-*`, `Raspberry-*`)로 개발되던 것을, 통합 시점의 `*-develop` 기준
스냅샷으로 한 폴더에 모은 것입니다. 원본 커밋 히스토리는 GitLab 쪽에 있습니다.

| 폴더 | 원본 브랜치 | 스택 | 역할 |
|---|---|---|---|
| `app/` | App-develop | Flutter | 사용자 앱 (상태 확인, 원격 제어, 귀가 알림) |
| `server/` | Server-develop + 병합 대기 MR(demo-ready-defaults, yolo-cpu-inference) | Spring Boot | 판단/조율 서버, MQTT 브로커 연동, YOLO 추론 |
| `robot/` | Robot-develop | ROS2 (Jetson Orin Nano) | 자율주행/도킹, 음성 대화, LLM 브리지 |
| `raspberry/` | Raspberry-develop | Python (Raspberry Pi) | 센서 수집, 급수/송풍 액추에이터, 카메라 촬영 |

## 담당 파트 (gbw11)

전체 4개 파트 중 **`raspberry/`(장치 스테이션)를 전담**했고, `robot/`에서는 **LLM/음성 대화 서브시스템**을
맡아 협업했습니다. 커밋 기준 raspberry는 55개(사실상 전량), robot은 31개(2순위 기여자)입니다.

### `raspberry/` — 장치 스테이션 (전담)

- **초기 구조 설계**: 센서 수집기(`main.py`) / 인터랙티브 CLI(`cli/plant.py`) 골격, 표준 `logging` 도입
- **센서 통합**: 조도(BH1750), 온습도(DHT22/AHT20), 토양수분(ADS1115) + 수위 플로트 스위치
  - 수위 감지 흔들림(채터링) 방지 — 유지시간 필터 → 접촉 인정 기준 명시화로 반복 개선
  - 서버가 정한 실제 규약(`status/water-low`)에 맞춰 보고 방식 전환
- **급수 펌프**: MQTT 원격 제어, 급수량 계산 정확도 개선, 과급수 방지 안전 게이트(1회 상한/최소 간격/24시간 누적)
- **송풍 팬**: MQTT 원격 제어 (앱 송풍 버튼 연동)
- **카메라 파이프라인**: 원격 촬영 명령 수신/결과 회신, 파일명 규칙, 밝기 검사(경고 방식으로 설계),
  실패 시 재시도, 서버 업로드(`POST /api/v1/device/photos`), 녹색빛 색보정(화이트밸런스) 핫픽스
- **MQTT 인프라**: 하트비트 발행, device ID 정합성, 명령/결과 토픽을 서버 실제 규약에 맞춰 정렬
- **대화 안정성**: LLM 응답 끊김·EOF에도 죽지 않는 폴백 계층 보강
- **시연 대응**: 데모용 급수 간격/일일 상한 임시 조정

### `robot/` — LLM·음성 대화 서브시스템 (공동 작업)

- 라즈베리 LLM 모듈을 로봇의 `potner_llm` 패키지로 이식, 응답 검증 파이프라인(센서값 대조 팩트체크,
  실패 시 재생성/폴백) 구축
- 센서 데이터 조회 연동(파일/HTTP/콜백 소스), 대화 맥락 구성, 음성 서버를 로봇의 기본 두뇌로 연결
- 식물 시점 "일기" 생성 프롬프트(페르소나·형식·사실성 제약 + 템플릿 폴백)
- 음성 대화 웹서버, 서버 TTS 오디오 재생 파이프라인, 휴대폰 연동
- LLM 웹 도구 확장(날씨·식물 지식·뉴스·위키백과 검색), GMS Anthropic 프록시(Claude Opus)로 전환
- 전 파일 테스트 스위프로 webchat 버그 3건 수정
