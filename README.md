# S15P11E104 (통합)

SSAFY S15P11E104 프로젝트의 네 개 라인(App/Server/Robot/Raspberry)을 각 `*-develop` 브랜치 기준으로 한 폴더에 모은 스냅샷입니다.
원본 히스토리는 GitLab(`s15-webmobile3-sub1/S15P11E104`)에 있으며, 이 저장소는 통합 시점의 파일 스냅샷만 담고 있습니다.

| 폴더 | 원본 | 스택 |
|---|---|---|
| `app/` | App-develop | Flutter |
| `server/` | Server-develop + 병합 대기 중인 MR(demo-ready-defaults, yolo-cpu-inference) | Spring Boot |
| `robot/` | Robot-develop | ROS2 (Jetson) |
| `raspberry/` | Raspberry-develop | Python (Raspberry Pi) |
